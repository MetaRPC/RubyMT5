# MT5Sugar — Balance & Margin (High-Level API)

> 6 one-liners for the money numbers — each reads one account property as a plain `Float`.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Account#account_info_double`](../MT5Account/1.%20Account_Information/AccountInfoDouble.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/06_sugar_basics.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 6 methods

| Method | Returns | Property |
|--------|---------|----------|
| **`balance`** | `Float` | `:ACCOUNT_BALANCE` |
| **`equity`** | `Float` | `:ACCOUNT_EQUITY` |
| **`margin`** | `Float` | `:ACCOUNT_MARGIN` |
| **`free_margin`** | `Float` | `:ACCOUNT_MARGIN_FREE` |
| **`margin_level`** | `Float` | `:ACCOUNT_MARGIN_LEVEL` (percent) |
| **`profit`** | `Float` | `:ACCOUNT_PROFIT` (floating) |

---

## 📖 Method details

### `balance -> Float`

**Usage examples:**

1. Print it:
   ```ruby
   puts mt5.balance.round(2)
   ```
2. Empty-account guard:
   ```ruby
   abort "no funds" if mt5.balance <= 0
   ```
3. Risk budget (1% of balance):
   ```ruby
   risk = mt5.balance * 0.01
   ```

### `equity -> Float`

**Usage examples:**

1. Print it:
   ```ruby
   puts mt5.equity.round(2)
   ```
2. Floating P&L:
   ```ruby
   puts (mt5.equity - mt5.balance).round(2)
   ```
3. Equity-stop trigger:
   ```ruby
   mt5.close_all_positions if mt5.equity < mt5.balance * 0.9
   ```

### `margin -> Float`

**Usage examples:**

1. Used margin:
   ```ruby
   puts mt5.margin.round(2)
   ```
2. Margin utilisation:
   ```ruby
   puts "#{(100 * mt5.margin / mt5.equity).round(1)}% used"
   ```
3. Is anything open (by margin)?
   ```ruby
   puts mt5.margin.zero? ? "flat" : "in market"
   ```

### `free_margin -> Float`

**Usage examples:**

1. Available margin:
   ```ruby
   puts mt5.free_margin.round(2)
   ```
2. Can I afford this trade?
   ```ruby
   need = mt5.required_margin("EURUSD", 0.1, mt5.ask("EURUSD"))
   puts mt5.free_margin >= need ? "ok" : "too big"
   ```
3. Max lot shorthand:
   ```ruby
   puts mt5.max_lot("EURUSD", mt5.ask("EURUSD"))
   ```

### `margin_level -> Float`

**Usage examples:**

1. Percent:
   ```ruby
   puts "#{mt5.margin_level.round(1)}%"
   ```
2. Health gauge:
   ```ruby
   lvl = mt5.margin_level
   puts lvl.zero? ? "flat" : (lvl < 200 ? "⚠️ low" : "✅ healthy")
   ```
3. Margin-call watch:
   ```ruby
   warn "near margin call!" if mt5.margin_level.positive? && mt5.margin_level < 120
   ```

### `profit -> Float`

**Usage examples:**

1. Floating profit:
   ```ruby
   puts mt5.profit.round(2)
   ```
2. In profit?
   ```ruby
   puts mt5.profit.positive? ? "green" : "red"
   ```
3. Take-profit on the whole book:
   ```ruby
   mt5.close_all_positions if mt5.profit >= 100
   ```
