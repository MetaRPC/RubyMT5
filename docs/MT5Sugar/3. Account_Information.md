# MT5Sugar — Account Information (High-Level API)

> 3 helpers for the account snapshot and mode.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#account_info`](../MT5Service/1.%20Account_Methods.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/06_sugar_basics.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 3 methods

| Method | Returns |
|--------|---------|
| **`account_info`** | `Account` (Struct) |
| **`account_summary`** | `AccountSummaryData` (raw) |
| **`demo?`** | `Boolean` |

`Account` fields: `login, balance, equity, currency, leverage, trade_mode, company, server_time_utc`.

---

## 📖 Method details

### `account_info -> Account`

**Usage examples:**

1. Header line:
   ```ruby
   a = mt5.account_info
   puts "##{a.login} · #{a.balance} #{a.currency} · 1:#{a.leverage}"
   ```
2. Floating P&L:
   ```ruby
   a = mt5.account_info; puts (a.equity - a.balance).round(2)
   ```
3. Broker & server:
   ```ruby
   a = mt5.account_info; puts "#{a.company}"
   ```

### `account_summary -> AccountSummaryData`

The full raw summary (all margin fields) when the Struct isn't enough.

**Usage examples:**

1. Margin level:
   ```ruby
   puts mt5.account_summary.account_margin_level
   ```
2. Trade flags:
   ```ruby
   s = mt5.account_summary; puts "trade #{s.account_trade_allowed}  EA #{s.account_trade_expert}"
   ```
3. Server time → UTC:
   ```ruby
   puts Time.at(mt5.account_summary.server_time_utc.seconds).utc
   ```

### `demo? -> Boolean`

**Usage examples:**

1. Refuse real accounts:
   ```ruby
   abort "demo only!" unless mt5.demo?
   ```
2. Size by mode:
   ```ruby
   vol = mt5.demo? ? 0.10 : 0.01
   ```
3. Log the mode:
   ```ruby
   puts "mode: #{mt5.demo? ? 'DEMO' : 'LIVE'}"
   ```
