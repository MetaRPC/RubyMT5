# MT5Sugar — History & Statistics (High-Level API)

> 2 helpers for closed history — orders+deals, and round-trips. Both auto-page and take a UTC start.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#order_history`](../MT5Service/3.%20Position_Orders_Methods.md) / `positions_history`.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/09_sugar_history.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 2 methods

| Method | Returns |
|--------|---------|
| **`order_history(from_utc:, **opts)`** | `[HistoryData]` (orders + deals) |
| **`positions_history(from_utc:, **opts)`** | `[PositionHistoryInfo]` (round-trips) |

> `**opts`: `to_utc:` (default now), `sort:`, `page_size:`.

---

## 📖 Method details

### `order_history(from_utc:, **opts) -> [HistoryData]`

**Usage examples:**

1. Last 7 days of deals:
   ```ruby
   mt5.order_history(from_utc: Time.now.utc - 7*24*3600).each do |h|
     d = h.history_deal; puts "deal ##{d.ticket} #{d.profit}" if d
   end
   ```
2. Realized P&L:
   ```ruby
   total = mt5.order_history(from_utc: Time.now.utc - 30*24*3600)
              .filter_map { |h| h.history_deal&.profit }.sum
   puts total.round(2)
   ```
3. A calendar window:
   ```ruby
   mt5.order_history(from_utc: Time.utc(2025,1,1), to_utc: Time.utc(2025,2,1))
   ```

### `positions_history(from_utc:, **opts) -> [PositionHistoryInfo]`

**Usage examples:**

1. Closed round-trips:
   ```ruby
   mt5.positions_history(from_utc: Time.now.utc - 7*24*3600).each do |p|
     puts "##{p.position_ticket} #{p.symbol} #{p.profit}"   # note: position_ticket
   end
   ```
2. Win rate:
   ```ruby
   rows = mt5.positions_history(from_utc: Time.now.utc - 30*24*3600)
   puts "#{(100.0 * rows.count { |p| p.profit.positive? } / rows.size).round(1)}%"
   ```
3. Best / worst:
   ```ruby
   rows = mt5.positions_history(from_utc: Time.now.utc - 30*24*3600)
   puts "best #{rows.max_by(&:profit)&.profit}  worst #{rows.min_by(&:profit)&.profit}"
   ```
