# MT5Sugar — Prices & Quotes (High-Level API)

> 4 one-liners for the current market.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#quote`](../MT5Service/2.%20Symbol_Methods.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/06_sugar_basics.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

## 📋 All 4 methods

| Method | Returns |
|--------|---------|
| **`bid(symbol)`** | `Float` |
| **`ask(symbol)`** | `Float` |
| **`spread(symbol)`** | `Float` (`ask - bid`) |
| **`price(symbol)`** | `Quote` (Struct) |

`Quote` fields: `symbol, bid, ask, last, spread, time_utc`.

---

## 📖 Method details

### `bid(symbol) -> Float`

**Usage examples:**

1. Print it:
   ```ruby
   puts mt5.bid("EURUSD")
   ```
2. Place a stop below bid:
   ```ruby
   sl = mt5.bid("EURUSD") - 0.0020
   ```
3. Poll a basket:
   ```ruby
   %w[EURUSD GBPUSD].each { |s| puts "#{s} #{mt5.bid(s)}" }
   ```

### `ask(symbol) -> Float`

**Usage examples:**

1. Print it:
   ```ruby
   puts mt5.ask("EURUSD")
   ```
2. Margin at the ask:
   ```ruby
   puts mt5.required_margin("EURUSD", 0.1, mt5.ask("EURUSD")).round(2)
   ```
3. Mid price:
   ```ruby
   puts ((mt5.bid("EURUSD") + mt5.ask("EURUSD")) / 2).round(5)
   ```

### `spread(symbol) -> Float`

**Usage examples:**

1. Price-unit spread:
   ```ruby
   puts mt5.spread("EURUSD").round(5)
   ```
2. Spread in points:
   ```ruby
   puts (mt5.spread("EURUSD") / mt5.symbol_point("EURUSD")).round
   ```
3. Skip wide spreads:
   ```ruby
   return if mt5.spread("EURUSD") / mt5.symbol_point("EURUSD") > 30
   ```

### `price(symbol) -> Quote`

**Usage examples:**

1. One snapshot, all fields:
   ```ruby
   q = mt5.price("EURUSD")
   puts "#{q.bid}/#{q.ask} spread #{q.spread.round(5)}"
   ```
2. Tick age:
   ```ruby
   q = mt5.price("EURUSD"); puts "#{Time.now.utc.to_i - q.time_utc}s old"
   ```
3. Pre-trade snapshot:
   ```ruby
   q = mt5.price("EURUSD"); mt5.buy_market("EURUSD", 0.01) if q.spread < 0.0002
   ```
