# MT5Sugar — Connection (High-Level API)

> 6 helpers to build the stack and manage the terminal session.

**🧩 API Layer:** **HIGH-LEVEL** — delegates to [`MT5Service`](../MT5Service/1.%20Account_Methods.md) → [`MT5Account`](../MT5Account/MT5Account.Master.Overview.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** every `examples/demos/**` file (connected by `main.rb`).

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 6 methods

| Method | Returns |
|--------|---------|
| **`MT5Sugar.create(host, port, **opts)`** | `MT5Sugar` (whole stack) |
| **`connect(login, password, server:, **opts)`** | `ConnectData` |
| **`connect_by_host(login, password, host:, port:, **opts)`** | `ConnectData` |
| **`quick_connect(login, password, server)`** | `ConnectData` |
| **`connected?`** | `Boolean` |
| **`reconnect(force:)`** | `ReconnectData` |
| **`disconnect(delete:, reason:)`** | `DisconnectData` |

> `mt5.account` / `mt5.service` reach the layers below.

## 📖 Method details

### `MT5Sugar.create(host = "mt5.mrpc.pro", port = 443, **opts) -> MT5Sugar`

**Usage examples:**

1. Default endpoint:
   ```ruby
   mt5 = MetaRPC::MT5::MT5Sugar.create(api_key: ENV["MRPC_API_KEY"])
   ```
2. Stable terminal id per strategy:
   ```ruby
   id = MetaRPC::MT5::MT5Account.uuid5(MetaRPC::MT5::MT5Account::NAMESPACE_DNS, "my-bot")
   mt5 = MetaRPC::MT5::MT5Sugar.create("mt5.mrpc.pro", 443, api_key: ENV["MRPC_API_KEY"], id: id)
   ```
3. Reach down to a lower layer:
   ```ruby
   svc = mt5.service; acct = mt5.account
   ```

### `connect(login, password, server:, **opts) -> ConnectData`

ConnectEx by broker server name. Raises `InvalidLoginError` on bad credentials (never retry that).

**Usage examples:**

1. Basic connect:
   ```ruby
   mt5.connect(5057947437, "password", server: "MetaQuotes-Demo")
   ```
2. Name the terminal + longer login wait:
   ```ruby
   mt5.connect(5057947437, "password", server: "MetaQuotes-Demo", name: "bot", timeout_seconds: 180)
   ```
3. Handle a bad login:
   ```ruby
   begin
     mt5.connect(1, "wrong", server: "MetaQuotes-Demo")
   rescue MetaRPC::MT5::InvalidLoginError => e
     warn "bad login: #{e.message}"
   end
   ```

### `connect_by_host(login, password, host:, port:, **opts) -> ConnectData`

Connect by the broker's raw trade-server host:port (no cluster lookup).

**Usage examples:**

1. Direct host:
   ```ruby
   mt5.connect_by_host(5057947437, "password", host: "mt5.broker.com", port: 443)
   ```
2. With a name:
   ```ruby
   mt5.connect_by_host(5057947437, "password", host: "mt5.broker.com", port: 443, name: "bot")
   ```
3. Fallback after a cluster-name miss:
   ```ruby
   mt5.connect(5057947437, "password", server: "Broker-Live") rescue
     mt5.connect_by_host(5057947437, "password", host: "mt5.broker.com", port: 443)
   ```

### `quick_connect(login, password, server) -> ConnectData`

Positional-server shorthand for `connect`.

**Usage examples:**

1. One-liner:
   ```ruby
   mt5.quick_connect(5057947437, "password", "MetaQuotes-Demo")
   ```
2. From env:
   ```ruby
   mt5.quick_connect(ENV["MT5_LOGIN"].to_i, ENV["MT5_PASSWORD"], ENV["MT5_SERVER"])
   ```
3. Then read immediately:
   ```ruby
   mt5.quick_connect(5057947437, "password", "MetaQuotes-Demo"); puts mt5.balance
   ```

### `connected? -> Boolean`

**Usage examples:**

1. Guard:
   ```ruby
   abort "not connected" unless mt5.connected?
   ```
2. Status line:
   ```ruby
   puts mt5.connected? ? "online" : "offline"
   ```
3. Reconnect if dropped:
   ```ruby
   mt5.reconnect unless mt5.connected?
   ```

### `reconnect(force: false) -> ReconnectData`

**Usage examples:**

1. Soft reconnect:
   ```ruby
   mt5.reconnect
   ```
2. Force it:
   ```ruby
   mt5.reconnect(force: true)
   ```
3. On error recovery:
   ```ruby
   begin; mt5.balance; rescue GRPC::BadStatus; mt5.reconnect(force: true); end
   ```

### `disconnect(delete: false, reason: nil) -> DisconnectData`

**Usage examples:**

1. Keep the terminal warm:
   ```ruby
   mt5.disconnect
   ```
2. Free the terminal (trial = one per IP):
   ```ruby
   mt5.disconnect(delete: true)
   ```
3. With a reason:
   ```ruby
   mt5.disconnect(reason: "shift end")
   ```
