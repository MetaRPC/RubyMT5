# MT5Sugar — Market Depth (High-Level API)

> 3 helpers for the order book — the **add → read → release** lifecycle with short names.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#book_add`](../MT5Service/5.%20MarketDepth_Methods.md) / `book` / `book_release`.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 3 methods

| Method | Returns |
|--------|---------|
| **`book_add(symbol)`** | `Boolean` |
| **`book(symbol)`** | `MarketBookGetData` |
| **`book_release(symbol)`** | `Boolean` |

---

## 📖 Method details

### `book_add(symbol) -> Boolean`

**Usage examples:**

1. Subscribe:
   ```ruby
   mt5.book_add("EURUSD")
   ```
2. Guard:
   ```ruby
   abort "no DOM" unless mt5.book_add("EURUSD")
   ```
3. Basket:
   ```ruby
   %w[EURUSD GBPUSD].each { |s| mt5.book_add(s) }
   ```

### `book(symbol) -> MarketBookGetData`

**Usage examples:**

1. Count levels:
   ```ruby
   puts mt5.book("EURUSD").mql_book_infos.size
   ```
2. Top 5:
   ```ruby
   mt5.book("EURUSD").mql_book_infos.first(5).each { |l| puts "#{l.type} #{l.price} x #{l.volume}" }
   ```
3. Any depth?
   ```ruby
   puts mt5.book("EURUSD").mql_book_infos.any? ? "has DOM" : "empty"
   ```

### `book_release(symbol) -> Boolean`

**Usage examples:**

1. Release:
   ```ruby
   mt5.book_release("EURUSD")
   ```
2. Full lifecycle:
   ```ruby
   if mt5.book_add("EURUSD")
     puts mt5.book("EURUSD").mql_book_infos.size
     mt5.book_release("EURUSD")
   end
   ```
3. Release a basket:
   ```ruby
   %w[EURUSD GBPUSD].each { |s| mt5.book_release(s) }
   ```

> Always release what you add. Many FX symbols return an empty book.
