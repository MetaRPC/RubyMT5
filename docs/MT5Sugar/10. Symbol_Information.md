# MT5Sugar — Symbol Information (High-Level API)

> 11 helpers for symbol specs, precision, bars and sessions — the numbers you need to size and round orders.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service`](../MT5Service/2.%20Symbol_Methods.md) / [`MT5Account`](../MT5Account/2.%20Symbol_Information/Symbol_Information.Overview.md) symbol reads.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/10_sugar_advanced.rb`.

## 📖 Method details

### `symbol_info(symbol) -> SymbolParameters | nil`

**Usage examples:**

1. Lot limits:
   ```ruby
   s = mt5.symbol_info("EURUSD"); puts "min #{s.volume_min} step #{s.volume_step}"
   ```
2. Contract size:
   ```ruby
   puts mt5.symbol_info("EURUSD").trade_contract_size
   ```
3. Currencies:
   ```ruby
   s = mt5.symbol_info("EURUSD"); puts "#{s.currency_base}/#{s.currency_profit}"
   ```

### `all_symbols -> [String]`

**Usage examples:**

1. Count:
   ```ruby
   puts mt5.all_symbols.size
   ```
2. Filter:
   ```ruby
   mt5.all_symbols.grep(/^EUR/)
   ```
3. Is it listed?
   ```ruby
   puts mt5.all_symbols.include?("GBPUSD")
   ```

### `symbols_total(market_watch_only: false) -> Integer`

**Usage examples:**

1. All:
   ```ruby
   puts mt5.symbols_total
   ```
2. Market Watch:
   ```ruby
   puts mt5.symbols_total(market_watch_only: true)
   ```
3. Hidden count:
   ```ruby
   puts mt5.symbols_total - mt5.symbols_total(market_watch_only: true)
   ```

### `symbol_name(index, selected: false) -> String`

**Usage examples:**

1. First:
   ```ruby
   puts mt5.symbol_name(0)
   ```
2. First in Market Watch:
   ```ruby
   puts mt5.symbol_name(0, selected: true)
   ```
3. Walk a few:
   ```ruby
   (0...3).each { |i| puts mt5.symbol_name(i) }
   ```

### `symbol_available?(symbol) -> Boolean`

**Usage examples:**

1. Guard:
   ```ruby
   abort "unknown" unless mt5.symbol_available?("EURUSD")
   ```
2. Validate input:
   ```ruby
   puts mt5.symbol_available?("GBPUSD") ? "ok" : "no"
   ```
3. Filter:
   ```ruby
   %w[EURUSD FOO].select { |s| mt5.symbol_available?(s) }
   ```

### `symbol_digits(symbol) -> Integer`

**Usage examples:**

1. Digits:
   ```ruby
   puts mt5.symbol_digits("EURUSD")
   ```
2. Round a price:
   ```ruby
   puts 1.094237.round(mt5.symbol_digits("EURUSD"))
   ```
3. Pip size:
   ```ruby
   d = mt5.symbol_digits("EURUSD"); puts mt5.symbol_point("EURUSD") * ([3,5].include?(d) ? 10 : 1)
   ```

### `symbol_point(symbol) -> Float`

**Usage examples:**

1. Point:
   ```ruby
   puts mt5.symbol_point("EURUSD")
   ```
2. 100-point offset:
   ```ruby
   puts mt5.ask("EURUSD") + 100 * mt5.symbol_point("EURUSD")
   ```
3. Spread in points:
   ```ruby
   puts (mt5.spread("EURUSD") / mt5.symbol_point("EURUSD")).round
   ```

### `min_stop_level(symbol) -> Integer`

**Usage examples:**

1. Min stop (points):
   ```ruby
   puts mt5.min_stop_level("EURUSD")
   ```
2. Validate an SL distance:
   ```ruby
   dist = (mt5.bid("EURUSD") - sl) / mt5.symbol_point("EURUSD")
   puts dist >= mt5.min_stop_level("EURUSD") ? "ok" : "too close"
   ```
3. Minimum SL price:
   ```ruby
   min_sl = mt5.bid("EURUSD") - mt5.min_stop_level("EURUSD") * mt5.symbol_point("EURUSD")
   ```

### `bars(symbol, **opts) -> [PriceBar]`

**Usage examples:**

1. Last 5 H1 closes:
   ```ruby
   mt5.bars("EURUSD", timeframe: :H1, max_bars: 5).each { |b| puts b.close }
   ```
2. Daily range:
   ```ruby
   b = mt5.bars("EURUSD", timeframe: :D1, max_bars: 1).last; puts (b.high - b.low).round(5)
   ```
3. A window:
   ```ruby
   mt5.bars("EURUSD", timeframe: :M15, from_utc: Time.now.utc - 3600, to_utc: Time.now.utc)
   ```

### `session_quote` / `session_trade(symbol, day_of_week:, session_index:)`

**Usage examples:**

1. Monday quote window:
   ```ruby
   sq = mt5.session_quote("EURUSD", day_of_week: :MONDAY); puts "#{sq.from&.seconds} → #{sq.to&.seconds}"
   ```
2. Monday trade window:
   ```ruby
   st = mt5.session_trade("EURUSD", day_of_week: :MONDAY); puts st.from&.seconds
   ```
3. Is it tradable today?
   ```ruby
   day = Time.now.utc.strftime("%A").upcase.to_sym
   puts mt5.session_trade("EURUSD", day_of_week: day).from ? "open" : "closed"
   ```
