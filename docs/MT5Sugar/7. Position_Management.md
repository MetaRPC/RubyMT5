# MT5Sugar — Position Management (High-Level API)

> Close positions (one, all, or by symbol), plus raw order passthroughs for full control.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Account#order_close`](../MT5Account/4.%20Trading_Operations/OrderClose.md) / `order_send` / `order_modify`.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb` · `orchestrators/14_risk_manager.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 6 methods

| Method | Does |
|--------|------|
| **`close_position(ticket, volume:, slippage:)`** | close one (full or partial) |
| **`close_all_positions(slippage:)`** | close every open position |
| **`close_all_by_symbol(symbol, slippage:)`** | close all positions on a symbol |
| **`order_send(symbol:, type:, volume:, **opts)`** | raw order (any type/options) |
| **`order_modify(ticket:, **opts)`** | raw modify |
| **`order_close(ticket:, **opts)`** | raw close / delete pending |

---

## 📖 Method details

### `close_position(ticket, volume: nil, slippage: 10)`

**Usage examples:**

1. Full close:
   ```ruby
   out = mt5.close_position(123_456)
   puts out.returned_code == 10_009 ? "closed" : out.returned_code_description
   ```
2. Partial close:
   ```ruby
   mt5.close_position(123_456, volume: 0.05)
   ```
3. Close the newest on a symbol:
   ```ruby
   pos = mt5.open_positions(symbol: "EURUSD").max_by(&:ticket)
   mt5.close_position(pos.ticket) if pos
   ```

### `close_all_positions(slippage: 10)`

Closes every open position; returns an array of results.

**Usage examples:**

1. Flatten everything:
   ```ruby
   mt5.close_all_positions
   ```
2. Count how many closed:
   ```ruby
   puts "closed #{mt5.close_all_positions.size}"
   ```
3. Panic button on drawdown:
   ```ruby
   mt5.close_all_positions if mt5.profit < -100
   ```

### `close_all_by_symbol(symbol, slippage: 10)`

**Usage examples:**

1. Flatten one symbol:
   ```ruby
   mt5.close_all_by_symbol("EURUSD")
   ```
2. Results:
   ```ruby
   puts mt5.close_all_by_symbol("EURUSD").map(&:returned_code).inspect
   ```
3. Rotate out of a symbol:
   ```ruby
   mt5.close_all_by_symbol("GBPUSD"); mt5.buy_market("EURUSD", 0.01)
   ```

### `order_send(symbol:, type:, volume:, **opts)`

Raw passthrough — full control when a helper is too narrow (drop-in with the old flat client).

**Usage examples:**

1. Any order type:
   ```ruby
   mt5.order_send(symbol: "EURUSD", type: :buy_stop_limit, volume: 0.01, price: 1.1050, stop_limit_price: 1.1045)
   ```
2. Without checks:
   ```ruby
   mt5.order_send(symbol: "EURUSD", type: :buy, volume: 0.01, without_checks: true)
   ```
3. With expiry:
   ```ruby
   mt5.order_send(symbol: "EURUSD", type: :buy_limit, volume: 0.01, price: 1.0750, expiration_utc: Time.now.utc + 3600)
   ```

### `order_modify(ticket:, **opts)` · `order_close(ticket:, **opts)`

**Usage examples:**

1. Raw modify:
   ```ruby
   mt5.order_modify(ticket: 123_456, stop_loss: 1.0850)
   ```
2. Raw close:
   ```ruby
   mt5.order_close(ticket: 123_456)
   ```
3. Delete a pending order:
   ```ruby
   mt5.order_close(ticket: pending_ticket)
   ```
