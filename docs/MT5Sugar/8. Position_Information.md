# MT5Sugar — Position Information (High-Level API)

> 8 read-only helpers to list and summarize open positions.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#positions`](../MT5Service/3.%20Position_Orders_Methods.md) / `positions_total` / `opened_tickets`.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/08_sugar_positions.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

## 📖 Method details

### `open_positions(magic: nil, symbol: nil) -> [PositionInfo]`

**Usage examples:**

1. All:
   ```ruby
   mt5.open_positions.each { |p| puts "##{p.ticket} #{p.symbol} P/L #{p.profit}" }
   ```
2. One EA:
   ```ruby
   mt5.open_positions(magic: 600_001).sum(&:profit)
   ```
3. One symbol:
   ```ruby
   mt5.open_positions(symbol: "EURUSD").size
   ```

### `position(ticket) -> PositionInfo | nil`

**Usage examples:**

1. Lookup:
   ```ruby
   p = mt5.position(123_456); puts p&.profit
   ```
2. Break-even move:
   ```ruby
   p = mt5.position(123_456); mt5.modify_sl(p.ticket, p.price_open) if p
   ```
3. Exists?
   ```ruby
   puts mt5.position(123_456) ? "open" : "gone"
   ```

### `positions_by_symbol(symbol) -> [PositionInfo]`

**Usage examples:**

1. Count on a symbol:
   ```ruby
   puts mt5.positions_by_symbol("EURUSD").size
   ```
2. Net volume:
   ```ruby
   puts mt5.positions_by_symbol("EURUSD").sum(&:volume)
   ```
3. Tickets on a symbol:
   ```ruby
   mt5.positions_by_symbol("EURUSD").map(&:ticket)
   ```

### `has_position?(symbol) -> Boolean`

**Usage examples:**

1. Guard duplicate entries:
   ```ruby
   mt5.buy_market("EURUSD", 0.01) unless mt5.has_position?("EURUSD")
   ```
2. Status:
   ```ruby
   puts mt5.has_position?("EURUSD") ? "in EURUSD" : "flat on EURUSD"
   ```
3. Only manage if present:
   ```ruby
   mt5.close_all_by_symbol("EURUSD") if mt5.has_position?("EURUSD")
   ```

### `count_positions -> Integer`

**Usage examples:**

1. Count:
   ```ruby
   puts mt5.count_positions
   ```
2. Concurrency cap:
   ```ruby
   return if mt5.count_positions >= 5
   ```
3. Flat?
   ```ruby
   puts mt5.count_positions.zero? ? "flat" : "in market"
   ```

### `total_profit -> Float`

**Usage examples:**

1. Floating P&L over all:
   ```ruby
   puts mt5.total_profit.round(2)
   ```
2. Take-profit on the book:
   ```ruby
   mt5.close_all_positions if mt5.total_profit >= 100
   ```
3. Report:
   ```ruby
   puts mt5.total_profit.positive? ? "green" : "red"
   ```

### `profit_by_symbol(symbol) -> Float`

**Usage examples:**

1. One symbol's P&L:
   ```ruby
   puts mt5.profit_by_symbol("EURUSD").round(2)
   ```
2. Close winners on a symbol:
   ```ruby
   mt5.close_all_by_symbol("EURUSD") if mt5.profit_by_symbol("EURUSD") > 20
   ```
3. Compare two symbols:
   ```ruby
   puts [mt5.profit_by_symbol("EURUSD"), mt5.profit_by_symbol("GBPUSD")].inspect
   ```

### `open_tickets -> OpenedOrdersTicketsData`

**Usage examples:**

1. Position tickets:
   ```ruby
   p mt5.open_tickets.opened_position_tickets.to_a
   ```
2. Count cheaply:
   ```ruby
   puts mt5.open_tickets.opened_position_tickets.to_a.size
   ```
3. Pending order tickets:
   ```ruby
   p mt5.open_tickets.opened_orders_tickets.to_a
   ```
