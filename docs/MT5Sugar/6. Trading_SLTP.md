# MT5Sugar — Trading with SL/TP (High-Level API)

> Open a market position with protection attached, and adjust stops on an open position.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Account#order_send`](../MT5Account/4.%20Trading_Operations/OrderSend.md) / [`#order_modify`](../MT5Account/4.%20Trading_Operations/OrderModify.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 5 methods

| Method | Does |
|--------|------|
| **`buy_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`** | market buy + SL/TP |
| **`sell_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`** | market sell + SL/TP |
| **`modify_sl(ticket, stop_loss)`** | set/move the stop-loss |
| **`modify_tp(ticket, take_profit)`** | set/move the take-profit |
| **`modify_sl_tp(ticket, stop_loss:, take_profit:)`** | set both at once |

---

## 📖 Method details

### `buy_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`

**Usage examples:**

1. Fixed prices:
   ```ruby
   mt5.buy_market_with_sl_tp("EURUSD", 0.01, sl: 1.0800, tp: 1.1000)
   ```
2. Pip-based around the market:
   ```ruby
   pip = mt5.symbol_point("EURUSD") * 10
   q = mt5.price("EURUSD")
   mt5.buy_market_with_sl_tp("EURUSD", 0.01, sl: (q.bid - 20*pip).round(5), tp: (q.ask + 40*pip).round(5))
   ```
3. Tagged:
   ```ruby
   mt5.buy_market_with_sl_tp("EURUSD", 0.01, sl: 1.08, tp: 1.10, magic: 600_001)
   ```

### `sell_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`

**Usage examples:**

1. Fixed prices:
   ```ruby
   mt5.sell_market_with_sl_tp("EURUSD", 0.01, sl: 1.1050, tp: 1.0900)
   ```
2. 2:1 reward/risk:
   ```ruby
   q = mt5.price("EURUSD")
   mt5.sell_market_with_sl_tp("EURUSD", 0.01, sl: (q.ask + 0.0020).round(5), tp: (q.bid - 0.0040).round(5))
   ```
3. Check the retcode:
   ```ruby
   r = mt5.sell_market_with_sl_tp("EURUSD", 0.01, sl: 1.1050, tp: 1.0900); puts r.returned_code
   ```

### `modify_sl(ticket, stop_loss)`

**Usage examples:**

1. Set a stop-loss:
   ```ruby
   mt5.modify_sl(123_456, 1.0850)
   ```
2. Move to break-even:
   ```ruby
   pos = mt5.position(123_456); mt5.modify_sl(pos.ticket, pos.price_open) if pos
   ```
3. Trail behind bid:
   ```ruby
   mt5.modify_sl(123_456, (mt5.bid("EURUSD") - 0.0015).round(5))
   ```

### `modify_tp(ticket, take_profit)`

**Usage examples:**

1. Set a take-profit:
   ```ruby
   mt5.modify_tp(123_456, 1.1000)
   ```
2. Extend the target:
   ```ruby
   mt5.modify_tp(123_456, (mt5.ask("EURUSD") + 0.0050).round(5))
   ```
3. Remove it (0 = none):
   ```ruby
   mt5.modify_tp(123_456, 0.0)
   ```

### `modify_sl_tp(ticket, stop_loss:, take_profit:)`

**Usage examples:**

1. Both at once:
   ```ruby
   mt5.modify_sl_tp(123_456, stop_loss: 1.0850, take_profit: 1.1000)
   ```
2. From the entry price:
   ```ruby
   p = mt5.position(123_456)
   mt5.modify_sl_tp(p.ticket, stop_loss: p.price_open - 0.005, take_profit: p.price_open + 0.010) if p
   ```
3. Tighten on profit:
   ```ruby
   mt5.modify_sl_tp(123_456, stop_loss: (mt5.bid("EURUSD") - 0.0010).round(5), take_profit: 1.1050)
   ```
