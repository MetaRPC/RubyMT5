# MT5Sugar — Simple Trading (High-Level API)

> One-liners to open market and pending orders. Each returns `OrderSendData` — check `returned_code` (`10009` = DONE).

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Account#order_send`](../MT5Account/4.%20Trading_Operations/OrderSend.md).

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## ⚠️ Results, not exceptions

A broker rejection comes back as `returned_code` (not an exception). Only a **hard** failure raises (`ApiError` / `TradeOutcomeUnknown`). Always check the retcode.

## 📋 All methods

| Method | Order |
|--------|-------|
| **`buy_market(symbol, volume, **kw)`** (alias `buy`) | market buy |
| **`sell_market(symbol, volume, **kw)`** (alias `sell`) | market sell |
| **`buy_limit(symbol, volume, price, **kw)`** | pending buy limit |
| **`sell_limit(symbol, volume, price, **kw)`** | pending sell limit |
| **`buy_stop(symbol, volume, price, **kw)`** | pending buy stop |
| **`sell_stop(symbol, volume, price, **kw)`** | pending sell stop |

> `**kw`: `magic:`, `comment:`, `stop_loss:`, `take_profit:`, `slippage:`, …

---

## 📖 Method details

### `buy_market(symbol, volume, **kw)` *(alias `buy`)*

**Usage examples:**

1. Simple buy:
   ```ruby
   r = mt5.buy_market("EURUSD", 0.01)
   puts r.returned_code == 10_009 ? "##{r.order}" : r.returned_code_description
   ```
2. Tag with magic & comment:
   ```ruby
   mt5.buy_market("EURUSD", 0.01, magic: 600_001, comment: "entry")
   ```
3. Alias form:
   ```ruby
   mt5.buy("EURUSD", 0.01)
   ```

### `sell_market(symbol, volume, **kw)` *(alias `sell`)*

**Usage examples:**

1. Simple sell:
   ```ruby
   mt5.sell_market("EURUSD", 0.01)
   ```
2. With slippage:
   ```ruby
   mt5.sell_market("EURUSD", 0.01, slippage: 30)
   ```
3. Alias form:
   ```ruby
   mt5.sell("EURUSD", 0.01)
   ```

### `buy_limit(symbol, volume, price, **kw)`

**Usage examples:**

1. Below the market:
   ```ruby
   mt5.buy_limit("EURUSD", 0.01, (mt5.bid("EURUSD") - 0.0030).round(5))
   ```
2. With SL/TP:
   ```ruby
   px = (mt5.bid("EURUSD") - 0.0030).round(5)
   mt5.buy_limit("EURUSD", 0.01, px, stop_loss: px - 0.005, take_profit: px + 0.010)
   ```
3. Tagged:
   ```ruby
   mt5.buy_limit("EURUSD", 0.01, 1.0750, magic: 42)
   ```

### `sell_limit(symbol, volume, price, **kw)`

**Usage examples:**

1. Above the market:
   ```ruby
   mt5.sell_limit("EURUSD", 0.01, (mt5.ask("EURUSD") + 0.0030).round(5))
   ```
2. Tagged:
   ```ruby
   mt5.sell_limit("EURUSD", 0.01, 1.1050, comment: "fade")
   ```
3. Check the retcode:
   ```ruby
   r = mt5.sell_limit("EURUSD", 0.01, 1.1050); puts r.returned_code
   ```

### `buy_stop(symbol, volume, price, **kw)`

Breakout above the market.

**Usage examples:**

1. Above the ask:
   ```ruby
   mt5.buy_stop("EURUSD", 0.01, (mt5.ask("EURUSD") + 0.0030).round(5))
   ```
2. With a stop-loss:
   ```ruby
   px = (mt5.ask("EURUSD") + 0.0030).round(5)
   mt5.buy_stop("EURUSD", 0.01, px, stop_loss: px - 0.004)
   ```
3. Tagged:
   ```ruby
   mt5.buy_stop("EURUSD", 0.01, 1.1050, magic: 7)
   ```

### `sell_stop(symbol, volume, price, **kw)`

Breakout below the market.

**Usage examples:**

1. Below the bid:
   ```ruby
   mt5.sell_stop("EURUSD", 0.01, (mt5.bid("EURUSD") - 0.0030).round(5))
   ```
2. With a stop-loss:
   ```ruby
   px = (mt5.bid("EURUSD") - 0.0030).round(5)
   mt5.sell_stop("EURUSD", 0.01, px, stop_loss: px + 0.004)
   ```
3. Tagged:
   ```ruby
   mt5.sell_stop("EURUSD", 0.01, 1.0750, comment: "break")
   ```
