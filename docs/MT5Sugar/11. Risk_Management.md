# MT5Sugar — Risk Management (High-Level API)

> 3 helpers to size and price a trade before you send it.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT5Service#order_calc_margin`](../MT5Service/4.%20Trading_Methods.md) / `order_calc_profit` + `free_margin`.

**Implementation:** `lib/metarpc_mt5/mt5_sugar.rb`. **Demos:** `examples/demos/sugar/10_sugar_advanced.rb`.

[← MT5Sugar Overview](./MT5Sugar.API_Overview.md)

---

## 📋 All 3 methods

| Method | Returns |
|--------|---------|
| **`required_margin(symbol, volume, price, type:)`** | `Float` (margin, account currency) |
| **`calc_profit(symbol, volume, open_price, close_price, type:)`** | `Float` (profit) |
| **`max_lot(symbol, price, type:)`** | `Float` (largest lot fitting free margin) |

> `type:` defaults to `:buy`.

---

## 📖 Method details

### `required_margin(symbol, volume, price, type: :buy) -> Float`

**Usage examples:**

1. Margin for 0.1 lot:
   ```ruby
   puts mt5.required_margin("EURUSD", 0.1, mt5.ask("EURUSD")).round(2)
   ```
2. Does it fit?
   ```ruby
   need = mt5.required_margin("EURUSD", 1.0, mt5.ask("EURUSD"))
   puts need <= mt5.free_margin ? "ok" : "too big"
   ```
3. Sell side:
   ```ruby
   mt5.required_margin("EURUSD", 0.1, mt5.bid("EURUSD"), type: :sell)
   ```

### `calc_profit(symbol, volume, open_price, close_price, type: :buy) -> Float`

**Usage examples:**

1. +100 points on 0.1 lot:
   ```ruby
   ask = mt5.ask("EURUSD"); pt = mt5.symbol_point("EURUSD")
   puts mt5.calc_profit("EURUSD", 0.1, ask, ask + 100*pt).round(2)
   ```
2. Value of a stop (risk):
   ```ruby
   puts mt5.calc_profit("EURUSD", 0.1, 1.10, 1.095).round(2)   # negative
   ```
3. Risk/reward:
   ```ruby
   r = mt5.calc_profit("EURUSD", 0.1, 1.10, 1.095)
   w = mt5.calc_profit("EURUSD", 0.1, 1.10, 1.115)
   puts "R:R = 1:#{(w / -r).round(2)}"
   ```

### `max_lot(symbol, price, type: :buy) -> Float`

Largest volume that fits free margin, rounded to the symbol's volume step. `0.0` when one lot already exceeds free margin.

**Usage examples:**

1. Max affordable:
   ```ruby
   puts mt5.max_lot("EURUSD", mt5.ask("EURUSD"))
   ```
2. Trade a fraction of it:
   ```ruby
   vol = (mt5.max_lot("EURUSD", mt5.ask("EURUSD")) * 0.25).round(2)
   mt5.buy_market("EURUSD", vol) if vol.positive?
   ```
3. Short side:
   ```ruby
   puts mt5.max_lot("EURUSD", mt5.bid("EURUSD"), type: :sell)
   ```
