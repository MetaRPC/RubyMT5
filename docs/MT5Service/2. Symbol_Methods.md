# MT5Service — Symbol Methods (Mid-Level API)

> 15 methods for quotes, symbol properties, specs, sessions and bars — a typed `Quote` plus plain-argument reads.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT5Account` · Symbol Information](../MT5Account/2.%20Symbol_Information/Symbol_Information.Overview.md) / Additional Methods.

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`.
**Demos:** `examples/demos/service/04_service_demo.rb` · `05_service_streaming.rb`.

## 📖 Method details

### `quote(symbol) -> Quote`

**Usage examples:**

1. Bid / ask / spread:
   ```ruby
   q = service.quote("EURUSD"); puts "#{q.bid}/#{q.ask} spread #{q.spread.round(5)}"
   ```
2. Mid price:
   ```ruby
   q = service.quote("EURUSD"); puts ((q.bid + q.ask) / 2).round(5)
   ```
3. Tick freshness:
   ```ruby
   q = service.quote("EURUSD"); puts "#{Time.now.utc.to_i - q.time_utc}s old"
   ```

### `tick(symbol) -> MrpcMqlTick`

**Usage examples:**

1. Raw tick volume:
   ```ruby
   puts service.tick("EURUSD").volume
   ```
2. Spread in points:
   ```ruby
   t = service.tick("EURUSD"); pt = service.account.symbol_info_double("EURUSD", :SYMBOL_POINT)
   puts ((t.ask - t.bid) / pt).round
   ```
3. Last deal price (0 on FX):
   ```ruby
   puts service.tick("XAUUSD").last
   ```

### `symbols -> [String]`

**Usage examples:**

1. Count & sample:
   ```ruby
   s = service.symbols; puts "#{s.size} symbols, first #{s.first}"
   ```
2. Filter by prefix:
   ```ruby
   service.symbols.grep(/^EUR/).each { |s| puts s }
   ```
3. Is a symbol listed?
   ```ruby
   puts service.symbols.include?("GBPUSD")
   ```

### `symbols_total(market_watch_only:) -> Integer`

**Usage examples:**

1. All symbols:
   ```ruby
   puts service.symbols_total
   ```
2. Market-Watch only:
   ```ruby
   puts service.symbols_total(market_watch_only: true)
   ```
3. How many are hidden:
   ```ruby
   puts service.symbols_total - service.symbols_total(market_watch_only: true)
   ```

### `symbol_name(index, selected:) -> String`

**Usage examples:**

1. First symbol:
   ```ruby
   puts service.symbol_name(0)
   ```
2. First Market-Watch symbol:
   ```ruby
   puts service.symbol_name(0, selected: true)
   ```
3. Walk a few:
   ```ruby
   (0...3).each { |i| puts service.symbol_name(i) }
   ```

### `symbol_exist?(symbol) -> Boolean`

**Usage examples:**

1. Guard a read:
   ```ruby
   abort "unknown symbol" unless service.symbol_exist?("EURUSD")
   ```
2. Validate user input:
   ```ruby
   sym = "GBPUSD"; puts service.symbol_exist?(sym) ? "ok" : "no such symbol"
   ```
3. Filter a list:
   ```ruby
   %w[EURUSD FOO BAR].select { |s| service.symbol_exist?(s) }
   ```

### `symbol_synchronized?(symbol) -> Boolean`

**Usage examples:**

1. One-shot check:
   ```ruby
   puts service.symbol_synchronized?("EURUSD")
   ```
2. Wait until synced:
   ```ruby
   sleep 0.2 until service.symbol_synchronized?("XAUUSD")
   ```
3. Select then confirm:
   ```ruby
   service.select_symbol("GBPUSD"); puts service.symbol_synchronized?("GBPUSD")
   ```

### `select_symbol(symbol, select = true) -> Boolean`

**Usage examples:**

1. Show in Market Watch:
   ```ruby
   service.select_symbol("GBPUSD")
   ```
2. Hide it again:
   ```ruby
   service.select_symbol("GBPUSD", false)
   ```
3. Ensure before reading:
   ```ruby
   service.select_symbol("XAUUSD"); q = service.quote("XAUUSD")
   ```

### `symbol_params(symbol) -> SymbolParameters | nil`

**Usage examples:**

1. Lot limits:
   ```ruby
   sp = service.symbol_params("EURUSD"); puts "min #{sp.volume_min} step #{sp.volume_step}"
   ```
2. Pip size:
   ```ruby
   sp = service.symbol_params("EURUSD")
   puts sp.point * ([3, 5].include?(sp.digits) ? 10 : 1)
   ```
3. Currencies:
   ```ruby
   sp = service.symbol_params("EURUSD"); puts "#{sp.currency_base}/#{sp.currency_profit}"
   ```

### `symbol_params_all(sort:) -> [SymbolParameters]`

**Usage examples:**

1. Count specs:
   ```ruby
   puts service.symbol_params_all.size
   ```
2. Index by name (cache it):
   ```ruby
   specs = service.symbol_params_all.to_h { |s| [s.name, s] }
   ```
3. Smallest min-lot symbols:
   ```ruby
   service.symbol_params_all.min_by(&:volume_min)
   ```

### `margin_rate(symbol, type) -> SymbolInfoMarginRateData`

**Usage examples:**

1. Initial / maintenance:
   ```ruby
   mr = service.margin_rate("EURUSD", :buy)
   puts "#{mr.initial_margin_rate} / #{mr.maintenance_margin_rate}"
   ```
2. Buy vs sell:
   ```ruby
   %i[buy sell].each { |t| puts "#{t}: #{service.margin_rate('EURUSD', t).initial_margin_rate}" }
   ```
3. Pending type:
   ```ruby
   puts service.margin_rate("EURUSD", :buy_limit).initial_margin_rate
   ```

### `tick_value_with_size(symbols) -> TickValueWithSizeData`

**Usage examples:**

1. One symbol (PascalCase accessors):
   ```ruby
   tv = service.tick_value_with_size("EURUSD").symbol_tick_size_infos.first
   puts "value #{tv.TradeTickValue} size #{tv.TradeTickSize}"
   ```
2. Several at once:
   ```ruby
   service.tick_value_with_size(%w[EURUSD GBPUSD]).symbol_tick_size_infos.each { |x| puts "#{x.Name} #{x.TradeTickValue}" }
   ```
3. Money per point:
   ```ruby
   tv = service.tick_value_with_size("EURUSD").symbol_tick_size_infos.first
   pt = service.account.symbol_info_double("EURUSD", :SYMBOL_POINT)
   puts (tv.TradeTickValue * (pt / tv.TradeTickSize)).round(4)
   ```

### `session_quote(symbol, day_of_week:, session_index:) -> …`

**Usage examples:**

1. Monday quote session:
   ```ruby
   sq = service.session_quote("EURUSD", day_of_week: :MONDAY)
   puts "#{sq.from&.seconds}s → #{sq.to&.seconds}s"
   ```
2. Whole week:
   ```ruby
   %i[MONDAY TUESDAY WEDNESDAY THURSDAY FRIDAY].each { |d| puts "#{d}: #{service.session_quote('EURUSD', day_of_week: d).from&.seconds}" }
   ```
3. Second session of a day:
   ```ruby
   service.session_quote("XAUUSD", day_of_week: :MONDAY, session_index: 1)
   ```

### `session_trade(symbol, day_of_week:, session_index:) -> …`

**Usage examples:**

1. Monday trade session:
   ```ruby
   st = service.session_trade("EURUSD", day_of_week: :MONDAY)
   puts "#{st.from&.seconds}s → #{st.to&.seconds}s"
   ```
2. Compare quote vs trade window:
   ```ruby
   q = service.session_quote("EURUSD", day_of_week: :MONDAY)
   t = service.session_trade("EURUSD", day_of_week: :MONDAY)
   puts "quote #{q.from&.seconds} / trade #{t.from&.seconds}"
   ```
3. Sunday (often closed):
   ```ruby
   service.session_trade("EURUSD", day_of_week: :SUNDAY)
   ```

### `bars(symbol, timeframe:, …) -> [PriceBar]`

**Usage examples:**

1. Last 5 H1 closes:
   ```ruby
   service.bars("EURUSD", timeframe: :H1, max_bars: 5).each { |b| puts b.close }
   ```
2. Daily range of the last bar:
   ```ruby
   b = service.bars("EURUSD", timeframe: :D1, max_bars: 1).last
   puts (b.high - b.low).round(5)
   ```
3. A date window:
   ```ruby
   service.bars("EURUSD", timeframe: :M15, from_utc: Time.now.utc - 3600, to_utc: Time.now.utc)
   ```
