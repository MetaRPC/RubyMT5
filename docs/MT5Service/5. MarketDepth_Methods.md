# MT5Service — Market Depth Methods (Mid-Level API)

> 3 methods for the order book (DOM): subscribe, read, release — the **add → get → release** lifecycle with shorter names.

**🧩 API Layer:** **MID-LEVEL** — a facade over [`MT5Account` · Market Depth](../MT5Account/5.%20Market_Depth(DOM)/Market_Depth.Overview.md).

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`.

[← MT5Service Overview](./MT5Service.Overview.md)

---

## 📋 All 3 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`book_add(symbol)`** | `Boolean` | `market_book_add(symbol)` |
| **`book(symbol)`** | `MarketBookGetData` | `market_book_get(symbol)` |
| **`book_release(symbol)`** | `Boolean` | `market_book_release(symbol)` |

---

## 📖 Method details

### `book_add(symbol) -> Boolean`

**Usage examples:**

1. Subscribe:
   ```ruby
   service.book_add("EURUSD")
   ```
2. Guard before reading:
   ```ruby
   abort "no DOM" unless service.book_add("EURUSD")
   ```
3. Subscribe several:
   ```ruby
   %w[EURUSD GBPUSD].each { |s| service.book_add(s) }
   ```

### `book(symbol) -> MarketBookGetData`

**Usage examples:**

1. Count levels:
   ```ruby
   puts service.book("EURUSD").mql_book_infos.size
   ```
2. Top 5 levels:
   ```ruby
   service.book("EURUSD").mql_book_infos.first(5).each { |l| puts "#{l.type} #{l.price} x #{l.volume}" }
   ```
3. Best bid / ask from the book:
   ```ruby
   levels = service.book("EURUSD").mql_book_infos
   puts "levels: #{levels.size}" if levels.any?
   ```

### `book_release(symbol) -> Boolean`

**Usage examples:**

1. Release one:
   ```ruby
   service.book_release("EURUSD")
   ```
2. Full add → read → release:
   ```ruby
   if service.book_add("EURUSD")
     puts service.book("EURUSD").mql_book_infos.size
     service.book_release("EURUSD")
   end
   ```
3. Release everything you added:
   ```ruby
   %w[EURUSD GBPUSD].each { |s| service.book_release(s) }
   ```

> Always **release what you add** — leaving subscriptions open wastes gateway resources. Many FX symbols return an **empty** book.
