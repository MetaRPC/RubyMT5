# MT5Service — Trading Methods (Mid-Level API)

> 6 methods to place, modify and close orders, plus the pre-trade calculators — plain arguments, same exactly-once safety as the low layer.

**🧩 API Layer:** **MID-LEVEL** — a facade over [`MT5Account` · Trading Operations](../MT5Account/4.%20Trading_Operations/Trading_Operations.Overview.md).

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`.
**Demos:** `examples/demos/service/04_service_demo.rb`.

[← MT5Service Overview](./MT5Service.Overview.md)

---

## ⚠️ Exactly-once trade safety

`order_send` / `order_modify` / `order_close` are **sent once and never re-sent**. A transport failure after the request may have reached the terminal is raised as a **`TradeOutcomeUnknown`**-marked error — check positions/history before retrying. Trade retcode **`10009` = DONE**. See [Return Codes](../All_Guides/RETURN_CODES_REFERENCE.md).

## 📋 All 6 methods

| Method | Returns |
|--------|---------|
| **`order_send(symbol:, type:, volume:, **opts)`** | `OrderSendData` |
| **`order_modify(ticket:, **opts)`** | `OrderModifyData` |
| **`order_close(ticket:, volume:, slippage:)`** | `OrderCloseData` |
| **`order_check(request)`** | `OrderCheckData` |
| **`order_calc_margin(symbol:, type:, volume:, price:)`** | `Float` |
| **`order_calc_profit(symbol:, type:, volume:, open_price:, close_price:)`** | `Float` |

> `type:` — `:buy` / `:sell` / `:buy_limit` / `:sell_limit` / `:buy_stop` / `:sell_stop` / `:buy_stop_limit` / `:sell_stop_limit`.

## 📖 Method details

### `order_send(symbol:, type:, volume:, **opts) -> OrderSendData`

Options: `price:`, `stop_loss:`, `take_profit:`, `comment:`, `magic:`, `slippage:`, `stop_limit_price:`, `expiration_type:`, `expiration_utc:`, `without_checks:`.

**Usage examples:**

1. Market buy:
   ```ruby
   r = service.order_send(symbol: "EURUSD", type: :buy, volume: 0.1, magic: 600_001)
   puts r.returned_code == 10_009 ? "✅ ##{r.order}" : "❌ #{r.returned_code_description}"
   ```
2. Market buy with SL/TP:
   ```ruby
   service.order_send(symbol: "EURUSD", type: :buy, volume: 0.1, stop_loss: 1.08, take_profit: 1.09)
   ```
3. Pending buy-limit below market:
   ```ruby
   bid = service.quote("EURUSD").bid
   service.order_send(symbol: "EURUSD", type: :buy_limit, volume: 0.1, price: (bid - 0.003).round(5))
   ```

### `order_modify(ticket:, **opts) -> OrderModifyData`

**Usage examples:**

1. Set a stop-loss:
   ```ruby
   service.order_modify(ticket: 123_456, stop_loss: 1.085)
   ```
2. Set both SL and TP:
   ```ruby
   service.order_modify(ticket: 123_456, stop_loss: 1.08, take_profit: 1.10)
   ```
3. Move a pending order's price:
   ```ruby
   service.order_modify(ticket: 123_456, price: 1.0750)
   ```

### `order_close(ticket:, volume:, slippage:) -> OrderCloseData`

**Usage examples:**

1. Full close:
   ```ruby
   out = service.order_close(ticket: 123_456)
   puts out.returned_code == 10_009 ? "closed" : out.returned_code_description
   ```
2. Partial close (half):
   ```ruby
   service.order_close(ticket: 123_456, volume: 0.05)
   ```
3. Delete a pending order:
   ```ruby
   service.order_close(ticket: pending_ticket)   # pending → deleted
   ```

### `order_check(request) -> OrderCheckData`

**Usage examples:**

1. Validate before sending:
   ```ruby
   req = Mt5TermApi::MrpcMqlTradeRequest.new(symbol: "EURUSD", volume: 0.1,
           order_type: :ORDER_TYPE_TF_BUY, price: service.quote("EURUSD").ask)
   service.order_check(req)
   ```
2. Affordability gate:
   ```ruby
   res = service.order_check(req)
   abort "would be rejected" unless res.mql_trade_check_result
   ```
3. Reuse for several volumes:
   ```ruby
   [0.1, 1.0, 5.0].each do |v|
     r = Mt5TermApi::MrpcMqlTradeRequest.new(symbol: "EURUSD", volume: v, order_type: :ORDER_TYPE_TF_BUY, price: ask)
     puts "#{v}: #{service.order_check(r).mql_trade_check_result ? 'ok' : 'no'}"
   end
   ```

### `order_calc_margin(symbol:, type:, volume:, price:) -> Float`

**Usage examples:**

1. Margin for 0.1 lot:
   ```ruby
   ask = service.quote("EURUSD").ask
   puts service.order_calc_margin(symbol: "EURUSD", type: :buy, volume: 0.1, price: ask).round(2)
   ```
2. Fits free margin?
   ```ruby
   need = service.order_calc_margin(symbol: "EURUSD", type: :buy, volume: 1.0, price: ask)
   puts need <= service.account_info_double(:ACCOUNT_MARGIN_FREE) ? "ok" : "too big"
   ```
3. Compare buy vs sell:
   ```ruby
   %i[buy sell].each { |t| puts "#{t}: #{service.order_calc_margin(symbol: 'EURUSD', type: t, volume: 0.1, price: ask).round(2)}" }
   ```

### `order_calc_profit(symbol:, type:, volume:, open_price:, close_price:) -> Float`

**Usage examples:**

1. +100 points on 0.1 lot:
   ```ruby
   ask = service.quote("EURUSD").ask; pt = service.symbol_params("EURUSD").point
   puts service.order_calc_profit(symbol: "EURUSD", type: :buy, volume: 0.1, open_price: ask, close_price: ask + 100*pt).round(2)
   ```
2. Short scenario:
   ```ruby
   service.order_calc_profit(symbol: "EURUSD", type: :sell, volume: 0.1, open_price: 1.10, close_price: 1.09)
   ```
3. Risk/reward of an SL/TP:
   ```ruby
   risk   = service.order_calc_profit(symbol: "EURUSD", type: :buy, volume: 0.1, open_price: 1.10, close_price: 1.095)
   reward = service.order_calc_profit(symbol: "EURUSD", type: :buy, volume: 0.1, open_price: 1.10, close_price: 1.115)
   puts "R:R = #{(reward / -risk).round(2)}"
   ```
