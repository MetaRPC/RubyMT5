# MT5Service — Streaming Methods (Mid-Level API)

> 6 methods for real-time streams. Each returns a `Subscription` running on a background thread — plus a blocking `each_tick` helper for scripts.

**🧩 API Layer:** **MID-LEVEL** — a facade over [`MT5Account` · Streaming](../MT5Account/7.%20Streaming_Methods/Streaming_Methods.Overview.md).

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`.
**Demos:** `examples/demos/service/05_service_streaming.rb`.

[← MT5Service Overview](./MT5Service.Overview.md)

---

## 🔌 The stream contract

Each streaming method takes a **block** and returns a `MetaRPC::MT5::Subscription`:

```ruby
sub = service.subscribe_ticks("EURUSD") { |q| puts "#{q.bid}/#{q.ask}" }
sub.cancel        # stop & join the reader thread
```

`sub.cancel` stops cleanly; `sub.alive?` / `sub.count` / `sub.error` inspect it. Keep block handlers **short** — they run on the reader thread.

---

## 📋 All 6 methods

| Method | Yields | Low-level equivalent |
|--------|--------|----------------------|
| **`subscribe_ticks(symbols)`** | a tick per update | `on_symbol_tick` |
| **`on_trade`** | `OnTradeData` | `on_trade` |
| **`on_position_profit(interval_ms:, ignore_empty:)`** | `OnPositionProfitData` | `on_position_profit` |
| **`on_tickets(interval_ms:)`** | ticket snapshots | `on_positions_and_pending_orders_tickets` |
| **`on_trade_transaction`** | `OnTradeTransactionData` | `on_trade_transaction` |
| **`each_tick(symbols, seconds:)`** | *(blocking)* → `Integer` | subscribe + sleep + cancel |

## 📖 Method details

### `subscribe_ticks(symbols) { |tick| … } -> Subscription`

**Usage examples:**

1. One symbol:
   ```ruby
   sub = service.subscribe_ticks("EURUSD") { |t| puts "#{t.bid}/#{t.ask}" }
   sleep 5; sub.cancel
   ```
2. Several symbols:
   ```ruby
   service.subscribe_ticks(%w[EURUSD GBPUSD]) { |t| puts "#{t.symbol} #{t.bid}" }
   ```
3. Count ticks:
   ```ruby
   n = 0; sub = service.subscribe_ticks("EURUSD") { n += 1 }
   sleep 3; sub.cancel; puts "#{n} ticks"
   ```

### `each_tick(symbols, seconds:) { |tick| … } -> Integer`

The blocking convenience: subscribe, iterate for `seconds`, auto-cancel, return the count.

**Usage examples:**

1. Collect for 4 s:
   ```ruby
   puts service.each_tick("EURUSD", seconds: 4) { |t| puts t.bid }
   ```
2. Track the high:
   ```ruby
   hi = 0.0; service.each_tick("EURUSD", seconds: 5) { |t| hi = [hi, t.ask].max }
   puts "high #{hi}"
   ```
3. Multiple symbols:
   ```ruby
   service.each_tick(%w[EURUSD GBPUSD], seconds: 3) { |t| puts t.symbol }
   ```

### `on_trade { |event| … } -> Subscription`

**Usage examples:**

1. Log events:
   ```ruby
   sub = service.on_trade { |ev| puts "event #{ev.type}" }
   sleep 10; sub.cancel
   ```
2. Re-read the book on a change:
   ```ruby
   service.on_trade { |_ev| puts service.positions_total }
   ```
3. Count events in a window:
   ```ruby
   n = 0; sub = service.on_trade { n += 1 }; sleep 5; sub.cancel; puts n
   ```

### `on_position_profit(interval_ms:, ignore_empty:) { |data| … } -> Subscription`

**Usage examples:**

1. Floating P/L every second:
   ```ruby
   service.on_position_profit(interval_ms: 1000) { |d| puts d.updated_positions.sum(&:profit).round(2) }
   ```
2. Alert on drawdown:
   ```ruby
   service.on_position_profit { |d| puts "⚠️" if d.updated_positions.sum(&:profit) < -50 }
   ```
3. Count updated positions:
   ```ruby
   sub = service.on_position_profit { |d| puts d.updated_positions.size }; sleep 5; sub.cancel
   ```

### `on_tickets(interval_ms:) { |data| … } -> Subscription`

**Usage examples:**

1. Watch ticket sets:
   ```ruby
   sub = service.on_tickets(interval_ms: 1000) { |_d| }; sleep 5; sub.cancel
   ```
2. Detect new opens cheaply (diff snapshots):
   ```ruby
   last = []
   service.on_tickets { |d| cur = d.opened_position_tickets.to_a; puts (cur - last).inspect; last = cur }
   ```
3. Short poll:
   ```ruby
   service.on_tickets(interval_ms: 500) { |_d| }
   ```

### `on_trade_transaction { |data| … } -> Subscription`

**Usage examples:**

1. Raw transaction feed:
   ```ruby
   sub = service.on_trade_transaction { |txn| puts txn.inspect[0, 80] }
   sleep 10; sub.cancel
   ```
2. Count transactions:
   ```ruby
   n = 0; sub = service.on_trade_transaction { n += 1 }; sleep 5; sub.cancel; puts n
   ```
3. Error-safe reader:
   ```ruby
   sub = service.on_trade_transaction { |_t| }
   sleep 5; sub.cancel; warn sub.error if sub.error
   ```
