# MT5Service — Position & Order Methods (Mid-Level API)

> 6 methods for reading what's open now and what's closed — with Ruby-side filtering and auto-paged history.

**🧩 API Layer:** **MID-LEVEL** — a facade over [`MT5Account` · Positions & Orders](../MT5Account/3.%20Position_Orders_Information/Position_Orders_Information.Overview.md).

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`.
**Demos:** `examples/demos/service/04_service_demo.rb`.

[← MT5Service Overview](./MT5Service.Overview.md)

---

## 📋 All 6 methods

| Method | Returns |
|--------|---------|
| **`positions_total`** | `Integer` |
| **`opened_orders(sort:)`** | `OpenedOrdersData` |
| **`opened_tickets`** | `OpenedOrdersTicketsData` |
| **`positions(magic:, symbol:)`** | `[PositionInfo]` (filtered) |
| **`order_history(from_utc:, to_utc:, sort:, page_size:)`** | `[HistoryData]` (auto-paged) |
| **`positions_history(from_utc:, to_utc:, sort:, page_size:)`** | `[PositionHistoryInfo]` (auto-paged) |

`PositionInfo` fields: `ticket`, `symbol`, `type`, `volume`, `price_open`, `price_current`, `stop_loss`, `take_profit`, `profit`, `swap`, `magic_number`, `comment`, … (see [OpenedOrders](../MT5Account/3.%20Position_Orders_Information/OpenedOrders.md)).

## 📖 Method details

### `positions_total -> Integer`

**Usage examples:**

1. Quick count:
   ```ruby
   puts "open: #{service.positions_total}"
   ```
2. Gate new entries:
   ```ruby
   return if service.positions_total >= 5   # max 5 concurrent
   ```
3. Flat check:
   ```ruby
   puts service.positions_total.zero? ? "flat" : "in market"
   ```

### `opened_orders(sort:) -> OpenedOrdersData`

**Usage examples:**

1. Positions vs pending:
   ```ruby
   d = service.opened_orders
   puts "positions #{d.position_infos.size}  pending #{d.opened_orders.size}"
   ```
2. Sorted newest first:
   ```ruby
   service.opened_orders(sort: :BMT5_OPENED_ORDER_SORT_BY_OPEN_TIME_DESC)
   ```
3. Total floating P/L:
   ```ruby
   puts service.opened_orders.position_infos.sum(&:profit).round(2)
   ```

### `opened_tickets -> OpenedOrdersTicketsData`

**Usage examples:**

1. Count cheaply:
   ```ruby
   puts service.opened_tickets.opened_position_tickets.to_a.size
   ```
2. Diff against a snapshot:
   ```ruby
   before = service.opened_tickets.opened_position_tickets.to_a
   # ... later ...
   after = service.opened_tickets.opened_position_tickets.to_a
   puts "new: #{(after - before).inspect}"
   ```
3. Pending order ids:
   ```ruby
   p service.opened_tickets.opened_orders_tickets.to_a
   ```

### `positions(magic:, symbol:) -> [PositionInfo]`

**Usage examples:**

1. All open positions:
   ```ruby
   service.positions.each { |p| puts "##{p.ticket} #{p.symbol} P/L #{p.profit}" }
   ```
2. One EA's positions:
   ```ruby
   service.positions(magic: 600_001).sum(&:profit)
   ```
3. One symbol's positions:
   ```ruby
   service.positions(symbol: "EURUSD").size
   ```

### `order_history(from_utc:, …) -> [HistoryData]`

**Usage examples:**

1. Last 7 days of deals:
   ```ruby
   service.order_history(from_utc: Time.now.utc - 7*24*3600).each do |h|
     d = h.history_deal; puts "deal ##{d.ticket} #{d.profit}" if d
   end
   ```
2. Realized P/L:
   ```ruby
   total = service.order_history(from_utc: Time.now.utc - 30*24*3600)
                  .filter_map { |h| h.history_deal&.profit }.sum
   puts total.round(2)
   ```
3. A specific window:
   ```ruby
   service.order_history(from_utc: Time.utc(2025, 1, 1), to_utc: Time.utc(2025, 2, 1))
   ```

### `positions_history(from_utc:, …) -> [PositionHistoryInfo]`

**Usage examples:**

1. Closed round-trips:
   ```ruby
   service.positions_history(from_utc: Time.now.utc - 7*24*3600).each do |p|
     puts "##{p.position_ticket} #{p.symbol} #{p.profit}"   # note: position_ticket
   end
   ```
2. Win rate:
   ```ruby
   rows = service.positions_history(from_utc: Time.now.utc - 30*24*3600)
   puts "#{(100.0 * rows.count { |p| p.profit.positive? } / rows.size).round(1)}%"
   ```
3. Best / worst trade:
   ```ruby
   rows = service.positions_history(from_utc: Time.now.utc - 30*24*3600)
   puts "best #{rows.max_by(&:profit)&.profit}  worst #{rows.min_by(&:profit)&.profit}"
   ```

> **Gotcha:** `PositionHistoryInfo` exposes `position_ticket` (not `ticket`).
