# MT5Service — Account Methods (Mid-Level API)

> 6 methods for reading account state — a typed snapshot, plus direct property reads — without protobuf ceremony.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT5Account`](../MT5Account/1.%20Account_Information/Account_Information.Overview.md) that returns plain Ruby types and a typed `Account` Struct.

**Implementation:** `lib/metarpc_mt5/mt5_service.rb`, wrapping `account_summary` / `account_info_{double,integer,string}` on `MT5Account`.

**Demos:** `examples/demos/service/04_service_demo.rb`.

[← MT5Service Overview](./MT5Service.Overview.md) · [low-level group ↓](../MT5Account/1.%20Account_Information/Account_Information.Overview.md)

## 📋 All 6 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`account_info`** | `Account` (Struct) | `account_summary`, composed |
| **`account_summary`** | `AccountSummaryData` | `account_summary` (raw passthrough) |
| **`demo?`** | `Boolean` | `account_summary.account_trade_mode == :..._DEMO` |
| **`account_info_double(property)`** | `Float` | `account_info_double(property)` |
| **`account_info_integer(property)`** | `Integer` | `account_info_integer(property)` |
| **`account_info_string(property)`** | `String` | `account_info_string(property)` |

---

## 📦 `Account` (Struct)

Returned by `account_info`:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `login` | `Integer` | Account number. |
| `balance` | `Float` | Balance (without floating P&L). |
| `equity` | `Float` | Equity (balance + floating P&L). |
| `currency` | `String` | Deposit currency. |
| `leverage` | `Integer` | Leverage (100 = 1:100). |
| `trade_mode` | `Symbol` | `:MRPC_ACCOUNT_TRADE_MODE_DEMO` / `_CONTEST` / `_REAL`. |
| `company` | `String` | Broker name. |
| `server_time_utc` | `Timestamp` | Broker server time in UTC (read `.seconds`). |

## 📖 Method details

### `account_info -> Account`

The account as one typed Struct.

**Usage examples:**

1. One-line status:
   ```ruby
   a = service.account_info
   puts "##{a.login} on #{a.company} · #{a.balance} #{a.currency} · 1:#{a.leverage}"
   ```
2. Floating P&L (equity − balance):
   ```ruby
   a = service.account_info
   puts "floating: #{(a.equity - a.balance).round(2)} #{a.currency}"
   ```
3. Guard before a run:
   ```ruby
   a = service.account_info
   abort "empty account" if a.balance <= 0
   ```

### `account_summary -> AccountSummaryData`

The full raw summary (every field, including all margin fields) when the Struct isn't enough.

**Usage examples:**

1. Margin level:
   ```ruby
   puts service.account_summary.account_margin_level
   ```
2. Full margin picture:
   ```ruby
   s = service.account_summary
   puts "used #{s.account_margin}  free #{s.account_margin_free}  level #{s.account_margin_level}%"
   ```
3. Terminal / trade flags:
   ```ruby
   s = service.account_summary
   puts "trade allowed? #{s.account_trade_allowed}  EA allowed? #{s.account_trade_expert}"
   ```

### `demo? -> Boolean`

**Usage examples:**

1. Refuse to trade on a real account:
   ```ruby
   abort "refusing to trade on a REAL account" unless service.demo?
   ```
2. Branch behaviour by mode:
   ```ruby
   volume = service.demo? ? 0.10 : 0.01
   ```
3. Log the mode once at startup:
   ```ruby
   puts "mode: #{service.demo? ? 'DEMO' : 'LIVE'}"
   ```

### `account_info_double(property) -> Float`

One numeric property — pass an `ACCOUNT_*` symbol.

**Usage examples:**

1. Free margin before sizing:
   ```ruby
   puts "free margin: #{service.account_info_double(:ACCOUNT_MARGIN_FREE).round(2)}"
   ```
2. Floating profit:
   ```ruby
   p = service.account_info_double(:ACCOUNT_PROFIT)
   puts p.positive? ? "+#{p.round(2)}" : p.round(2)
   ```
3. Margin-level gauge:
   ```ruby
   lvl = service.account_info_double(:ACCOUNT_MARGIN_LEVEL)
   puts lvl.zero? ? "flat" : (lvl < 200 ? "⚠️ low" : "✅ healthy")
   ```

### `account_info_integer(property) -> Integer`

**Usage examples:**

1. Leverage & login:
   ```ruby
   puts "##{service.account_info_integer(:ACCOUNT_LOGIN)} · 1:#{service.account_info_integer(:ACCOUNT_LEVERAGE)}"
   ```
2. Is automated trading allowed?
   ```ruby
   puts service.account_info_integer(:ACCOUNT_TRADE_EXPERT) == 1 ? "EAs ok" : "EAs off"
   ```
3. Margin mode:
   ```ruby
   puts ["netting", "exchange", "hedging"][service.account_info_integer(:ACCOUNT_MARGIN_MODE)]
   ```

### `account_info_string(property) -> String`

**Usage examples:**

1. Currency & company:
   ```ruby
   puts "#{service.account_info_string(:ACCOUNT_COMPANY)} — #{service.account_info_string(:ACCOUNT_CURRENCY)}"
   ```
2. Trade server:
   ```ruby
   puts "server: #{service.account_info_string(:ACCOUNT_SERVER)}"
   ```
3. Account holder:
   ```ruby
   puts "holder: #{service.account_info_string(:ACCOUNT_NAME)}"
   ```

> The full property enums are listed on the low-level pages: [AccountInfoDouble](../MT5Account/1.%20Account_Information/AccountInfoDouble.md) · [Integer](../MT5Account/1.%20Account_Information/AccountInfoInteger.md) · [String](../MT5Account/1.%20Account_Information/AccountInfoString.md).
