    MT5Sugar — Streaming (High-Level API)¶

    6 helpers for real-time streams. Each returns a Subscription (background thread) — plus a blocking each_tick.

    🧩 API Layer: HIGH-LEVEL — wraps MT5Service / MT5Account streams.

    Implementation: lib/metarpc_mt5/mt5_sugar.rb. Demos: examples/demos/sugar/* · lowlevel/03_streaming_methods.rb.

    ← MT5Sugar Overview

    🔌 The stream contract¶

    Each streaming method takes a block and returns a MetaRPC::MT5::Subscription:

    sub = mt5.subscribe_ticks("EURUSD") { |t| puts "#{t.bid}/#{t.ask}" }
sub.cancel          # stop & join the reader thread

    sub.cancel stops cleanly; sub.count / sub.error inspect it. Keep handlers short — they run on the reader thread.

    📋 All 6 methods¶

    Method Yields
    subscribe_ticks(symbols) a tick per update
    on_trade OnTradeData
    on_position_profit(interval_ms:, ignore_empty:) OnPositionProfitData
    on_tickets(interval_ms:) ticket snapshots
    on_trade_transaction OnTradeTransactionData
    each_tick(symbols, seconds:) (blocking) → Integer

    📖 Method details¶

    subscribe_ticks(symbols) { |tick| … }¶

    Usage examples:

    1. One symbol: 
      sub = mt5.subscribe_ticks("EURUSD") { |t| puts "#{t.bid}/#{t.ask}" }; sleep 5; sub.cancel
    2. Basket: 
      mt5.subscribe_ticks(%w[EURUSD GBPUSD]) { |t| puts "#{t.symbol} #{t.bid}" }
    3. Count: 
      n = 0; sub = mt5.subscribe_ticks("EURUSD") { n += 1 }; sleep 3; sub.cancel; puts n

    each_tick(symbols, seconds:) { |tick| … } -> Integer¶

    Blocking: subscribe, iterate for seconds, auto-cancel, return the count.

    Usage examples:

    1. Collect for 4 s: 
      puts mt5.each_tick("EURUSD", seconds: 4) { |t| puts t.bid }
    2. Track the high: 
      hi = 0.0; mt5.each_tick("EURUSD", seconds: 5) { |t| hi = [hi, t.ask].max }; puts hi
    3. Several symbols: 
      mt5.each_tick(%w[EURUSD GBPUSD], seconds: 3) { |t| puts t.symbol }

    on_trade · on_position_profit · on_tickets · on_trade_transaction¶

    Usage examples:

    1. Trade events: 
      sub = mt5.on_trade { |ev| puts ev.type }; sleep 10; sub.cancel
    2. Live floating P/L: 
      mt5.on_position_profit(interval_ms: 1000) { |d| puts d.updated_positions.sum(&:profit).round(2) }
    3. Ticket diffs / raw transactions: 
      mt5.on_tickets { |d| p d.opened_position_tickets.to_a }
mt5.on_trade_transaction { |txn| puts txn.inspect[0, 60] }
